# astrbot-plugin-peer

"像群友一样聊天"的人格与行为插件，主要用于 [AstrBot](https://github.com/AstrBotDevs/AstrBot)。本地小模型适配（这是整套系统里最核心的插件。

它决定机器人**要不要开口、用什么人格开口、开口前后处理**

## 功能

- **人格管理**：人格文本存在 `data/persona.json`，可在面板里编辑而不改源码；插件启动时把它写入 AstrBot 的人格行。文件缺失/损坏时不覆盖现有设置（不再内置默认人格）。
- **发言闸门**：`on_waiting_llm_request` 阶段做概率/规则判定，决定是否真的调用模型；回复后释放闸门状态。
- **群聊格式**：`on_llm_request` 钩子往提示词里加说话人格式说明；具体人设/回答要求都由 `persona.json` 提供，不在代码里重复。
- **表情包附带**：按概率给回复配一张表情（依赖 meme_manager 插件）。
- **输出后处理**：`on_decorating_result` 阶段丢掉模型误输出的空/None 回复，把 `&&表情&&` 标记挪到句末，套用文本替换规则，并按概率配表情包（见下方与表情插件的配合）。
- **水群定时器**：空闲时在群里低频搭话，冒泡语在 `main.py` 的 `OPENERS` 里配置。

## 与表情插件的配合

本插件负责把 `&&...&&` 标记整理到回复末尾；真正的"剥掉标记 + 从图库选图发送"由 `meme_manager` 插件完成。两插件通过文本标记协作，各自独立。
如果模型输出了图库里不存在的自造情绪词（如 `&&得意&&`），需要 `meme_manager` 的 `filter_all_tags` 开关做最终兜底清理，否则标记文本会残留成乱码。

## 配置文件

| 文件 | 用途 |
|---|---|
| `data/persona.json` | 人格文本（可面板编辑） |
| AstrBot 数据目录下的回复配置 | 表情概率、文本替换规则等 |

## 依赖

- AstrBot 4.28+
- 建议配合 `meme_manager`（表情包插件）使用；不装也能正常聊天，只是没有自动配图
- 人格与回复配置写在磁盘 JSON（运行数据，不随代码发布）
